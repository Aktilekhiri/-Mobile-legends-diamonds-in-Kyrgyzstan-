GamesDrop: проверка связи

Показывает баланс и ищет игру в каталоге. Ничего не покупает. Тестовый заказ отправляется только на тестовый оффер 999 (Steam US) и только по галочке.

Проверка игрока по ID

Ищет игру по полю «Поиск» выше (например mobile legends) и проверяет ID. Ничего не покупает.

Сравнение цен

FazerCards (наша себестоимость) против GamesDrop: MLBB и PUBG. Ничего не покупает. Минус % = GamesDrop дешевле.

Тест регионов

Берёт ID из доставленных заказов (Global, Россия, Турция, США) и проверяет их на офферах разных регионов. V = найден, x = нет. Ничего не покупает.

Проверка одного ID по всем регионам

Прогоняет этот ID и Zone по всем офферам Mobile Legends (Global, Россия, Турция и др.). V = найден, x = нет, у найденных показывается ник. Ничего не покупает.

Тест скорости MLBB (86 алмазов)

«Найти» только ищет оффер. «Купить» СПИСЫВАЕТ деньги с баланса GamesDrop (около 1,2 $) и замеряет секунды до выдачи на этот ID. Делайте по одному, с паузой.
